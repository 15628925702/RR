# 正式 P4 慢在哪、大概要多久

慢的不是 Frank–Wolfe，也不是解线性方程。每一次更新 \(\beta\) 都要重算 **观测信息 \(H\)** 和 **conditional score**，两者都卡在 GMM 缺失坐标的条件抽样上。拒绝抽样在远离 \(\beta^\star\) 时接受率会掉到 \(10^{-3}\) 乃至 \(10^{-6}\)，时间几乎全在进 Newton 盆之前的前两步。

锚定数字：G3 rejection 同格 **37.8 GPU 小时**；G3 QMC 同格 **1.2 小时**（快约 30 倍）；正式格子 3 × 5 × 50 = 750；外推机器 RTX 4080 SUPER。

## 1. 哪一环节慢

**吃掉几乎全部墙时**

- **估 \(H\)**：当前 \(\beta\) 上的 Fisher / 观测信息
- **算 conditional score**：更新方程里的条件得分
- 两者都要对缺失坐标做 GMM 条件抽样

**几乎可以忽略**

- Frank–Wolfe（正式 P4 用 oracle \(p^\star\)，设计步甚至是 0）
- 解 \(H^{-1}s\)、建 pilot、反解 \(\widetilde\beta\)
- 抽完整 target、算 KL

Phase 0 在 A800 上拍过一格：oracle 分配、\(B=8000\)、\(J=2\)、1 次 replication。墙时归因 **99.79%**，合计 12.4 秒。

| 环节 | 秒 | 占比 | 说明 |
| --- | ---: | ---: | --- |
| 估 \(H\) | 6.91 | 55.7% | 当前 \(\beta\) 上重估观测信息，内层是条件抽样 |
| conditional score | 4.01 | 32.3% | 更新方程，同样是条件抽样 |
| KL | 0.91 | 7.3% | 评估用，不进更新循环 |
| 抽完整 target | 0.34 | 2.7% | 倾斜定律抽 \(B\) 条完整向量 |
| \(\mu\) / pilot 反解 | 0.20 | 1.6% | 一次 |
| Frank–Wolfe / 线性代数 | ≈ 0 | < 0.1% | 不是瓶颈 |

该格还记下：条件提案约 14.8 亿次，接受约 580 万次，中位接受率 0.30%，最低 0.10%。720 次拒绝调用。Phase 0 说明「时间花在哪」；G3 才说明「远 pilot 上会有多肥的尾」。

## 2. 为什么拒绝抽样特别贵

条件抽样次数大致正比于 \(B\cdot L_U\cdot J/\)接受率。\(L_U=\lceil 32\log_2(B+1)\rceil\)，\(B=8000\) 时 \(L_U=415\)。接受率在远离 \(\beta^\star\) 时是肥尾：普通格 \(10^{-3}\) 量级，G3 最差 replication 可到 \(10^{-6}\)。

G3 rejection：\(B=8000\)、20 次、\(J=0\ldots 4\)，合计 **37.8 GPU 小时**（约 1.6 天）。中位 replication 约 1 小时，最慢一条 **13.7 小时**。时间几乎全在进盆前：

| 做到哪一步 | 累计均值（秒） | 含义 |
| --- | ---: | --- |
| \(J=2\) | 6746 | 约 1.9 小时已经花完；这就是进盆前的前两步 |
| \(J=4\) | 6795 | 后两步进盆之后只要约 50 秒 |

正式配置写成 \(J=2\) 也省不了多少：贵的就是前两步。进盆之后 \(\beta\) 靠近 \(\beta^\star\)，接受率回升，后面的 Fisher scoring 很快。QMC 同格只要 1.2 小时，比拒绝抽样快约 30 倍，是因为绕开了「远 \(\beta\) 上提案几乎全被拒」这条尾巴，不是因为少算了 \(H\) 或 score。

## 3. 正式 P4 外推多久

正式格子：Uniform / A-OSQD / oracle RR-GID，预算 \(\{2000,4000,8000,16000,32000\}\)，每格 50 次，共 750 格。五档预算相对只跑 \(B=8000\) 约 **8.4 倍体积**（\(B\cdot L_U\)），50/20 = 2.5 倍重复，三个政策各算一遍 H/score 再 ×3。大预算上拒绝抽样还会更肥，所以不能只乘体积比。

| 路径 | 算法 | 单卡连续跑 |
| --- | --- | --- |
| A. 现在这套拒绝抽样 | 有限 \(L_U\) 拒绝 | **约 2–3 个月**（约 60–100 天） |
| B. 先做性能重构，正式走 QMC | 与 G3 QMC 同阶 | **约 3–8 天 GPU**（约 77 小时再加排队） |
| C. 小预算拒绝 + 大预算 QMC | 审查指南允许的分层 | 约 2–4 周 |

路径 B 的 GPU 粗算：\(1.22\,\mathrm{h}\times 2.5\times 8.4\times 3\approx 77\,\mathrm{h}\)。从今天起，若先花几天做 QMC 大规模路径再开格子，最快大约两周出齐正式全表。G4 若审核要求先过，会再加一段 plugin 扫 120 个 panel 的 \(I_S\)，主耗时仍是正式 750 格。

墙时瓶颈已经定位：远 pilot 上的 \(H\) 与 conditional score 条件抽样，不是设计步。正式 P4 走拒绝抽样按月计，走 QMC 按天计。现在停在 G3，是为了先审核选哪条路径，避免一开就锁在几十天的拒绝抽样上。
